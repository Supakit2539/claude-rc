# คำนวณแสงสว่างตามขนาดพื้นที่

เว็บแอปหน้าเดียว (HTML/CSS/JS ล้วน ไม่ต้องติดตั้งอะไร) สำหรับคำนวณจำนวนหลอดไฟ/โคมที่เหมาะสมกับขนาดห้อง ด้วยวิธี **Lumen Method**

## วิธีใช้
เปิดไฟล์ `index.html` ในเบราว์เซอร์ได้ทันที แล้วกรอก:
1. ขนาดห้อง (ยาว × กว้าง × สูง) ความสูงระนาบใช้งาน และสีผนัง
2. ประเภทพื้นที่ (มีค่า lux แนะนำ) หรือกำหนดค่าเอง
3. ชนิดหลอด (มีค่าตั้งต้น LED/ฟลูออเรสเซนต์ ฯลฯ) จำนวนหลอดต่อโคม และสภาพแวดล้อม
4. ชั่วโมงใช้งานและค่าไฟต่อหน่วย

ผลลัพธ์: จำนวนโคม/หลอด, ความสว่างที่ได้จริง, มุมมองห้อง 3D (หมุน/ซูมได้ พร้อมลำแสงและแผนที่ความสว่าง) หรือผัง 2D, ความสม่ำเสมอของแสง, ระยะห่าง, W/ตร.ม. และค่าไฟต่อเดือน/ปี

## สูตร
```
N  = (E × A) / (Φ × n × UF × MF)
RI = (L × W) / (Hm × (L + W)),  Hm = ความสูงฝ้า − ความสูงระนาบใช้งาน
```
UF ประมาณจากตารางตามดัชนีห้อง (RI) และสีผนัง — ผลลัพธ์เป็นค่าประมาณเบื้องต้น ควรตรวจสอบกับข้อมูลโคมจริงจากผู้ผลิต

## นำเข้าไฟล์ IES / LDT
กด "นำเข้าไฟล์ IES / LDT ของโคมจริง" แล้วเลือกไฟล์ `.ies` (IESNA LM-63, โฟโตเมตรี Type C) หรือ `.ldt` (EULUMDAT รองรับสมมาตร Isym 0–4) จากผู้ผลิตโคม แอปจะ:
- อ่านฟลักซ์ของโคม กำลังไฟ ขนาดโคม และค่าความเข้มแสง (candela) ทุกมุม
- แสดงกราฟการกระจายแสงเชิงขั้ว (C0–C180 / C90–C270, cd/klm) มุมลำแสง และ LOR
- คำนวณแสงตรงแบบจุดต่อจุดจากข้อมูลจริง (ใช้กับเส้น isolux, ค่า lux รายจุด, U₀) และหมุนโคม 90° ได้
- ใส่ข้อมูลโฟโตเมตริกลงในรายงาน PDF

ไฟล์ตัวอย่าง (ข้อมูลสังเคราะห์สำหรับทดสอบ) อยู่ในโฟลเดอร์ `samples/`

## วาดแบบพื้นที่ (แท็บ "แก้ไขแบบ")
- **ผังห้อง:** คลิกวางมุมห้องทีละจุดเพื่อวาดห้องรูปทรงอิสระ (ล็อกแนว 0°/45°/90° และสแนปกริด 10 ซม. อัตโนมัติ) ลากมุมเพื่อแก้ ดับเบิลคลิกขอบเพื่อเพิ่มมุม
- **ผนัง:** วาดผนังภายใน กำหนดความหนาและความสูงได้ (ผนังเตี้ย/พาร์ทิชันก็ได้)
- **วัตถุ:** โต๊ะทำงาน โต๊ะประชุม เก้าอี้ โซฟา เตียง ตู้ ชั้นวาง เคาน์เตอร์ บันได เสา — ย้าย หมุน ปรับขนาด ทำสำเนา ลบได้
- **ประตู / หน้าต่าง:** คลิกบนผนังหรือขอบห้องเพื่อวาง (เกาะผนังอัตโนมัติ ลากเลื่อนตามแนวผนังได้) ปรับกว้าง สูง ระดับขอบล่างหน้าต่าง สลับด้านเปิดและบานพับประตูได้ — ผนังใน 3D ถูกเจาะช่องจริง และแสงลอดผ่านช่องเปิดในการคำนวณเงา
- **โคม:** ใช้การจัดวางอัตโนมัติตามรูปทรงห้อง (หลบผนังและเสา) หรือวางเองทีละดวง
- ย้อนกลับ/ทำซ้ำ (Ctrl+Z / Ctrl+Y), บันทึก/เปิดแบบเป็นไฟล์ .json, เบราว์เซอร์จำแบบล่าสุดไว้
- การคำนวณใช้พื้นที่และเส้นรอบรูปจริง (RI = 2A ÷ (Hm × P)) และคิดเงาจากผนังและเฟอร์นิเจอร์ที่สูงกว่าระนาบใช้งาน

## แสงธรรมชาติ (Daylight Factor)
- คำนวณจากหน้าต่างบนผนังภายนอกที่วาดไว้: Sky Component แบบจุดต่อจุดภายใต้ท้องฟ้าครึ้มมาตรฐาน CIE (คิดการบังจากผนังและเฟอร์นิเจอร์) + แสงสะท้อนภายใน (สูตร BRE)
- เลือกสภาพท้องฟ้า (5,000–30,000 lx) และชนิดกระจก (τ 0.3–0.8) ได้ คิดกรอบหน้าต่าง 0.8 และความสกปรกของกระจก 0.9
- แสดงผล DF เฉลี่ย/ต่ำสุด ความสว่างจากแสงธรรมชาติ ผลรวมกับแสงจากโคม และศักยภาพลดการใช้ไฟช่วงกลางวัน
- สลับแผนที่ความสว่าง/เส้น isolux ได้ระหว่าง "แสงจากโคม" "แสงธรรมชาติ" และ "รวมทั้งสอง" และมีหน้าแสงธรรมชาติในรายงาน PDF
- ไม่รวมแสงแดดส่องตรง แสงสะท้อนจากภายนอก และสิ่งบังภายนอกอาคาร

## เครื่องมือวาดอิสระแบบ SketchUp
- **ผนังโค้ง:** คลิกจุดเริ่ม → จุดปลาย → เลื่อนกำหนดความโค้ง; ผนังที่มีอยู่และ**ขอบห้อง**ดัดให้โค้งได้ด้วยการลากจุดกลาง (หรือใส่ค่าความโค้ง)
- **รูปทรง:** กล่อง (ลากสี่เหลี่ยม), ทรงกระบอก/เสากลม (จุดศูนย์กลาง + รัศมี), ทรงกลม, รูปทรงอิสระ (วาดรูปหลายเหลี่ยมแล้วยกความสูงแบบ Push/Pull)
- ทุกวัตถุกำหนด กว้าง/ลึก/สูง, **ยกจากพื้น** (เช่น ตู้แขวน), หมุน, สี ได้ และบังแสงตามความสูงจริง
- **วัดระยะ** (M) และคีย์ลัด V/P/W/C/M/R
- **นำเข้าโมเดล 3D:** .glb .gltf .obj .stl .dae .fbx .ply — เดาหน่วยในไฟล์ให้ (ม./ซม./มม./นิ้ว/ฟุต) ปรับสเกลและแกนตั้ง (Z-up) ได้ คำนวณเงาจากรูปทรงจริงด้านบน (convex hull) เก็บไฟล์ไว้ในเบราว์เซอร์ และฝังในไฟล์แบบ .json ที่บันทึก
- ไฟล์ .skp ของ SketchUp เปิดในเบราว์เซอร์ไม่ได้ ให้ Export จาก SketchUp เป็น .dae / .obj / .stl / .glb ก่อน
- ไฟล์ตัวอย่างอยู่ใน `samples/3d/`

## ความสว่างบนพื้นผิววัสดุ
- เลือก "แสดง: ความสว่างบนพื้นผิว (3D)" — ทุกพื้นผิว (พื้น ผนัง ผนังโค้ง เฟอร์นิเจอร์ รูปทรง โมเดลที่นำเข้า) ระบายสีตามค่า lux ของตัวเอง คำนวณรายพิกเซลบน GPU ตามมุมตกกระทบจริงและข้อมูล IES/LDT (ถ้ามี) พร้อมเงาจากผนัง/เฟอร์นิเจอร์ (ปิดได้)
- คลิกบนพื้นผิวใดก็ได้ในภาพ 3D เพื่ออ่านค่า lux ณ จุดนั้น
- ตาราง E_avg / E_min / E_max ของ พื้น, ผนังแต่ละด้าน, ผนังภายใน และผิวบนของวัตถุทุกชิ้น และมีหน้า "ความสว่างบนพื้นผิว" ในรายงาน PDF

## ความสมจริงของแสง
- **Radiosity (ค่าเริ่มต้น):** คำนวณแสงสะท้อนระหว่างพื้น ผนัง เพดาน และผนังภายในจริง (สะท้อน 6 รอบ ตามค่าสะท้อนแสงของพื้นผิว คิดการบังจากผนัง/เฟอร์นิเจอร์ และช่องประตู/หน้าต่าง) แล้วเก็บเป็น irradiance volume ให้ทุกพื้นผิวและระนาบใช้งานใช้ — มุมห้อง ใต้โต๊ะ และซอกหลังตู้มืดลงตามจริง เพดานได้แสงสะท้อน คำนวณใน Web Worker เบื้องหลัง; เลือกกลับเป็นแบบประมาณ (ตรงกับ Lumen Method) ได้
- **ภาพเสมือนจริง (3D):** แสดงพื้นผิวด้วยสีจริงที่ได้รับแสงตรง + แสงสะท้อน ตามสีของแสง (CCT) มีเงานุ่มสำหรับโคมขนาดใหญ่ (หลอดยาว แผง LED) tone mapping แบบกล้อง และปรับความสว่างภาพได้ — ปกรายงาน PDF ใช้ภาพนี้

## งานภายนอกอาคาร (ไฟถนน · สปอร์ตไลท์ · สนามฟุตบอล · ลานกว้าง)
สลับโหมดที่ปุ่ม "🌃 ภายนอกอาคาร" ด้านบน
- **ไฟถนน:** ความกว้างถนน/จำนวนช่องจราจร การจัดวาง (ด้านเดียว สองฝั่งสลับ สองฝั่งตรงกัน เกาะกลาง) ความสูงเสา ระยะยื่น มุมเงย — หาระยะห่างเสาที่กว้างที่สุดที่ผ่านเกณฑ์อัตโนมัติ เกณฑ์ EN 13201 คลาส M (แปลงเป็น lux โดยประมาณ), C, P
- **สนามฟุตบอล:** 4/6/8 เสา ความสูงเสา ระยะร่น — เล็งโคมอัตโนมัติ (greedy: แต่ละโคมเล็งจุดที่มืดที่สุดในโซนของเสา) และเลือกจำนวนโคม/มุมลำแสงที่ใช้กำลังไฟน้อยที่สุด เกณฑ์ EN 12193 Class I/II/III (Eh, U₂, U₁) พร้อมค่าความสว่างแนวตั้งหันหากล้อง
- **ฟลัดไลท์ลานกว้าง/ลานจอดรถ:** เลือกจำนวนเสา โคม และรุ่นโคมที่ใช้กำลังไฟน้อยที่สุด เกณฑ์ EN 12464-2
- โคมสำเร็จรูป (โคมถนน, ฟลัดไลท์, สปอร์ตไลท์ 15°–60°) หรือนำเข้า IES/LDT ของรุ่นจริง
- ผัง 2D พร้อมทิศเล็งโคม เส้น isolux ค่า lux ที่จุดคำนวณตามมาตรฐาน มุม 3D แบบแผนที่ความสว่างหรือภาพกลางคืนเสมือนจริง คลิกอ่านค่า lux และรายงาน PDF 6 หน้า (สรุปเทียบเกณฑ์ โคม ผังและตารางการเล็ง isolux ตารางค่า)
- ยังไม่คำนวณค่าความส่องสว่างผิวถนน (cd/m²), TI/GR (แสงบาด) และแสงรบกวนนอกพื้นที่
