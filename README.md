# คำนวณแสงสว่างตามขนาดพื้นที่

เว็บแอปหน้าเดียว (HTML/CSS/JS ล้วน ไม่ต้องติดตั้งอะไร) สำหรับคำนวณจำนวนหลอดไฟ/โคมที่เหมาะสมกับขนาดห้อง ด้วยวิธี **Lumen Method**

## วิธีใช้
เปิดไฟล์ `index.html` ในเบราว์เซอร์ได้ทันที แล้วกรอก:
1. ขนาดห้อง (ยาว × กว้าง × สูง) ความสูงระนาบใช้งาน และสีผนัง
2. ประเภทพื้นที่ (มีค่า lux แนะนำ) หรือกำหนดค่าเอง
3. ชนิดหลอด (มีค่าตั้งต้น LED/ฟลูออเรสเซนต์ ฯลฯ) จำนวนหลอดต่อโคม และสภาพแวดล้อม
4. ชั่วโมงใช้งานและค่าไฟต่อหน่วย

ผลลัพธ์: จำนวนโคม/หลอด, ความสว่างที่ได้จริง, มุมมองห้อง 3D (หมุน/ซูมได้ พร้อมลำแสงและแผนที่ความสว่าง) หรือผัง 2D, ความสม่ำเสมอของแสง, ระยะห่าง, W/ตร.ม. และค่าไฟต่อเดือน/ปี

## สูตร
```
N  = (E × A) / (Φ × n × UF × MF)
RI = (L × W) / (Hm × (L + W)),  Hm = ความสูงฝ้า − ความสูงระนาบใช้งาน
```
UF ประมาณจากตารางตามดัชนีห้อง (RI) และสีผนัง — ผลลัพธ์เป็นค่าประมาณเบื้องต้น ควรตรวจสอบกับข้อมูลโคมจริงจากผู้ผลิต

## นำเข้าไฟล์ IES / LDT
กด "นำเข้าไฟล์ IES / LDT ของโคมจริง" แล้วเลือกไฟล์ `.ies` (IESNA LM-63, โฟโตเมตรี Type C) หรือ `.ldt` (EULUMDAT รองรับสมมาตร Isym 0–4) จากผู้ผลิตโคม แอปจะ:
- อ่านฟลักซ์ของโคม กำลังไฟ ขนาดโคม และค่าความเข้มแสง (candela) ทุกมุม
- แสดงกราฟการกระจายแสงเชิงขั้ว (C0–C180 / C90–C270, cd/klm) มุมลำแสง และ LOR
- คำนวณแสงตรงแบบจุดต่อจุดจากข้อมูลจริง (ใช้กับเส้น isolux, ค่า lux รายจุด, U₀) และหมุนโคม 90° ได้
- ใส่ข้อมูลโฟโตเมตริกลงในรายงาน PDF

ไฟล์ตัวอย่าง (ข้อมูลสังเคราะห์สำหรับทดสอบ) อยู่ในโฟลเดอร์ `samples/`

## วาดแบบพื้นที่ (แท็บ "แก้ไขแบบ")
- **ผังห้อง:** คลิกวางมุมห้องทีละจุดเพื่อวาดห้องรูปทรงอิสระ (ล็อกแนว 0°/45°/90° และสแนปกริด 10 ซม. อัตโนมัติ) ลากมุมเพื่อแก้ ดับเบิลคลิกขอบเพื่อเพิ่มมุม
- **ผนัง:** วาดผนังภายใน กำหนดความหนาและความสูงได้ (ผนังเตี้ย/พาร์ทิชันก็ได้)
- **วัตถุ:** โต๊ะทำงาน โต๊ะประชุม เก้าอี้ โซฟา เตียง ตู้ ชั้นวาง เคาน์เตอร์ บันได เสา — ย้าย หมุน ปรับขนาด ทำสำเนา ลบได้
- **ประตู / หน้าต่าง:** คลิกบนผนังหรือขอบห้องเพื่อวาง (เกาะผนังอัตโนมัติ ลากเลื่อนตามแนวผนังได้) ปรับกว้าง สูง ระดับขอบล่างหน้าต่าง สลับด้านเปิดและบานพับประตูได้ — ผนังใน 3D ถูกเจาะช่องจริง และแสงลอดผ่านช่องเปิดในการคำนวณเงา
- **โคม:** ใช้การจัดวางอัตโนมัติตามรูปทรงห้อง (หลบผนังและเสา) หรือวางเองทีละดวง
- ย้อนกลับ/ทำซ้ำ (Ctrl+Z / Ctrl+Y), บันทึก/เปิดแบบเป็นไฟล์ .json, เบราว์เซอร์จำแบบล่าสุดไว้
- การคำนวณใช้พื้นที่และเส้นรอบรูปจริง (RI = 2A ÷ (Hm × P)) และคิดเงาจากผนังและเฟอร์นิเจอร์ที่สูงกว่าระนาบใช้งาน
