ตู้ FACP และการ์ด

  • CPU / Main board: มี SLC Loop 1, NAC 1–2, AUX 24V, ANN-BUS (RS-485 ไปจอแสดงผลระยะไกล) และรีเลย์ Alarm ในตัว
  • Main power supply: รับไฟ AC 220V จ่าย 24V ให้ระบบ และชาร์จแบตเตอรี่ 12V × 2 ที่ต่ออนุกรม
  • การ์ด Loop 2: เพิ่ม SLC อีกหนึ่ง loop Address แยกจาก Loop 1 (L2D001 คนละตัวกับ L1D001)
  • การ์ด DVC / Audio: ระบบเสียงประกาศอพยพ ให้วงจรลำโพง 25V ต่อเฉพาะลำโพงที่มีหม้อแปลง ห้ามต่อฮอร์น

SLC Loop และ Isolator

  • สาย SLC+/SLC− ต่อพ่วงหัวและโมดูลทุกตัว ขั้วต้องตรงกัน
  • Class B ออกขั้ว B จบที่ตัวสุดท้าย แยกสาย (T-tap) ได้ · Class A วนกลับเข้าขั้ว A ห้าม T-tap
  • ตั้ง Loop ของอุปกรณ์ในช่อง "อุปกรณ์ที่เลือก" ให้ตรงกับ loop ที่ต่อจริง ไม่งั้นตู้จะเห็นเป็น Unprogrammed
  • Isolator: ขา IN จากฝั่งตู้ ขา OUT ไปอุปกรณ์ถัดไป เมื่อช็อตจะตัดเฉพาะช่วงที่เสีย ควรติดใกล้ตู้และคั่นทุกโซน

โมดูลและอุปกรณ์ปลายทาง

  • Monitor: IDC ต่อหน้าสัมผัส NO ของแมนนวล, Flow switch, Tamper + EOL 47kΩ ที่ตัวสุดท้าย (Tamper แจ้งเป็น Supervisory)
  • Control: ต้องมีไฟ 24V จาก AUX ขา OUT ต่อฮอร์น/สโตรบ/กระดิ่งตามขั้ว + EOL 47kΩ
  • Relay: C/NO/NC เป็นหน้าสัมผัสแห้ง AHU ใช้ C–NC (ดับพัดลมตอน Alarm) ลิฟต์ใช้ C–NO (ปิดวงจรสั่ง Recall)
  • NAC บนตู้ใช้ EOL 2.2kΩ ฮอร์นต่อกลับขั้ว ตู้จะเห็นเป็น SHORT

อุปกรณ์เสริมภายนอก

  • Remote power supply (NAC extender): ขา IN รับสัญญาณจาก NAC ของตู้ (ต่อเหมือนฮอร์นตัวหนึ่ง แล้วย้าย EOL ของ NAC ตู้ไปไว้หลังขา IN) ขยาย NAC ได้อีก 2 วงจร ต้องมีแบตเตอรี่ของตัวเอง
  • Annunciator (จอแสดงผลระยะไกล): ต่อ ANN-BUS A→A, B→B และไฟ 24V จาก AUX ตั้ง Address 1–8 ห้ามซ้ำ
  • ทุกวงจรที่ตรวจสาย (IDC, NAC, ลำโพง) EOL ต้องอยู่ปลายสายเสมอ

ชื่อการ์ดและขั้วในแบบฝึกเป็นแบบกลาง ตู้จริง (เช่น Notifier รุ่นต่างๆ) มีชื่อการ์ด หมายเลขขั้ว ค่า EOL และพิกัดกระแสต่างกัน ให้ยึดคู่มือติดตั้งของรุ่นที่ใช้ มาตรฐาน วสท. และ NFPA 72
