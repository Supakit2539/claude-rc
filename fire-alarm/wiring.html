ผลตรวจแต่ละวงจร

ตั้ง Address (ปุ่มหมุนที่อุปกรณ์)

หัวตรวจจับ (D) กับโมดูล (M) ใช้ช่วงหมายเลขแยกกัน 1–159 ต่อ Loop ตั้งซ้ำกันในกลุ่มเดียวกันไม่ได้

หลักการต่อสายแต่ละวงจร

SLC Loop (สายสื่อสาร)

  • สาย 2 เส้น SLC+ / SLC− ต่อพ่วงหัวและโมดูลทุกตัวแบบขนาน ขั้วต้องตรงกันทุกตัว
  • Class B: ออกจากขั้ว B แล้วจบที่อุปกรณ์ตัวสุดท้าย แยกสาย (T-tap) ได้ ไม่มี EOL
  • Class A: ออกขั้ว B วนผ่านทุกตัวแล้วกลับเข้าขั้ว A สายขาดจุดเดียวยังสื่อสารได้ครบ ห้าม T-tap
  • นิยมใช้สายคู่ตีเกลียว 1.5 mm² มีชีลด์ ต่อชีลด์ลงกราวด์ที่ตู้ด้านเดียว และควรติด Isolator คั่นทุกโซน

Monitor module (รับสัญญาณหน้าสัมผัส)

  • ด้าน SLC ต่อเข้า loop เหมือนหัวตรวจจับ ด้าน IDC ต่อกับหน้าสัมผัส NO ของแมนนวล, Flow switch, Tamper
  • วาง EOL 47kΩ ที่อุปกรณ์ตัวสุดท้าย ตู้จึงจับสายขาดได้ (Open = Trouble)
  • หน้าสัมผัสปิด = ลัดวงจร IDC = ตู้มองเป็น ALARM (สายช็อตจึงทำให้ Alarm ได้)

Control module / NAC (สั่งฮอร์น-สโตรบ)

  • Control module ต้องมีไฟ 24VDC จากขั้ว AUX ของตู้ (หรือ Power supply ย่อย) แยกจาก SLC
  • ฮอร์นมีขั้ว: + ไป OUT+, − ไป OUT− ต่อพ่วงเข้า-ออกขั้วเดียวกัน แล้วจบที่ EOL 47kΩ
  • ตอนปกติตู้จ่ายไฟกลับขั้วเพื่อตรวจสาย ไดโอดในฮอร์นจะกันกระแส ถ้าต่อฮอร์นกลับขั้ว ตู้จะเห็นเป็น SHORT
  • NAC บนตู้ใช้ EOL 2.2kΩ (ค่าตามคู่มือรุ่นของตู้)

Relay module และแบตเตอรี่

  • Relay module ให้หน้าสัมผัสแห้ง C / NO / NC ไม่ตรวจสาย ใช้สั่ง AHU, ประตู, ลิฟต์
  • ปิดพัดลม AHU: ต่อสายควบคุมผ่าน C–NC ปกติวงจรปิด พัดลมทำงาน เมื่อ Alarm รีเลย์เปลี่ยนสถานะ พัดลมดับ
  • แบตเตอรี่ 12V 2 ลูก ต่ออนุกรม ได้ 24V: BAT+→(+)ลูก 1, (−)ลูก 1→(+)ลูก 2, (−)ลูก 2→BAT−

ชื่อขั้วในแบบฝึกเป็นแบบกลาง ขั้วจริงของแต่ละรุ่น (เช่นตู้ Notifier, ฐานหัว และโมดูล) มีหมายเลขขั้วต่างกัน ให้ยึดคู่มือติดตั้งของรุ่นนั้น มาตรฐาน วสท. และ NFPA 72
